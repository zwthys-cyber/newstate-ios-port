# 原 APK 全部菜单的迁移状态

用户要求覆盖全部游戏功能。下表记录实际状态，未完成项不在插件中提供可开启的空实现。静态定位和主机模型测试均不能替代实机验证。

| 原菜单类别 | 当前状态 | 待验证或实现的部分 |
| --- | --- | --- |
| 方框、连线、距离 | 已编写 iOS 只读显示 | 实机投影、视口比例；方框使用胶囊轮廓 |
| 血量 | 已编写 | Health/HealthMax 读取的实机结果 |
| 姓名 | 已编写常规 PlayerState FString 路径 | 自定义 GetPlayerName 虚拟分支未覆盖 |
| 中心准星 | 已编写 | 实机屏幕中心及横竖屏 |
| 骨架 | 已编写实验性读取与投影 | 实机骨骼父子关系、姿态缓冲、leader-pose 分支与对齐 |
| 头部红点 | 未实现 | 头骨名称/索引映射及实机验证 |
| 360° / 身后标记 | 未实现 | 屏外方向显示及投影验证 |
| 手雷预警 | 未实现 | NEW STATE 中投掷物类型、爆炸时间与有效状态 |
| 敌方武器 | 未实现 | 当前持枪、武器名称和队伍数据 |
| 载具分类 | 部分类型已编写位置标记 | 车型分类及新增载具覆盖 |
| 武器、瞄具、弹药、防具、药品、投掷物、配件等物资筛选 | 已编写掉落物/物资组位置标记 | 组内物资枚举、名称、数量与逐类筛选 |
| 空投、飞机、盒子等特殊物资 | 未实现 | 目标类和资源映射 |
| 自瞄开关、范围、头/胸/腰、准星/距离优先、开镜/开火条件、倒地目标 | 未实现 | 已定位 SetControlRotation 原生分发；尚缺队伍判断、目标骨骼、开火/开镜状态和正确线程/调用路径的验证 |
| 减后坐力、无后坐力 | 未实现 | 已定位 XtrmWeapon_Gun.RecoilScale，类型 Vector2D；尚缺当前武器归属、运行时覆盖及关闭恢复验证 |
| 平板视野 | 未实现 | 已定位相机 FOV；需要验证当前视角和开镜状态、更新及恢复路径 |
| 黑色人物 | 未实现 | 材质实例和渲染更新路径 |
| 去雾 / HD | 未实现 | 已定位 ExponentialHeightFogComponent 等字段；渲染状态更新路径和图形设置验证 |
| 小准星 | 已编写独立中心准星 | 原游戏武器散布准星的尺寸修改未实现 |
| 黑色天空 | 未实现 | 天空材质及环境组件 |
| 假爆头效果、X-kill 击杀效果 | 未实现 | NEW STATE 的本地表现资源与触发路径；没有已验证的跨游戏一对一实现 |
| 防抖 | 未实现 | 相机 shake 的实例、更新和恢复路径 |
| 车辆跳跃 | 未实现 | 当前载具、物理控制及服务器校验相关的实际行为 |
| Bypass | 无可移植的已验证实现 | Android 的 iptables 脚本不适用于 iOS，也不能据此声称能绕过保护 |

后续修改依赖先取得首版插件的设备加载、世界/相机读取和显示结果。当前不能交付“全部已完成”的结论。
