# 开发签名安装测试 IPA

独立的最小 UIKit 应用，iOS 17.0 或更高。用于按用户要求在全能签中重签安装，尝试通过开发签名安装流程使开发者模式入口出现。应用没有开关系统开发者模式的权限，不包含相关私有接口，不会请求重启、修复 TrollStore 或修改设备。界面仅显示手动操作说明。

Apple 说明：安装开发签名应用（即使不通过 Xcode）也能使开发者模式菜单显示。来源：https://developer.apple.com/videos/play/wwdc2022/110344/

使用条件与步骤：

1. 将 DeveloperModeCheck.ipa 导入全能签。
2. 使用 **Apple Development / iPhone Developer 开发证书及匹配的开发描述文件**签名安装。Distribution、Ad Hoc 或企业分发描述文件不能替代这个条件。不要凭“个人证书”营销名称判断类型；无需向任何人发送私钥。
3. 安装后检查“设置 → 隐私与安全性 → 开发者模式”。如果提示需要开发者模式，按系统指引处理；应用此时不能启动是预期可能发生的情况。
4. 若开关出现，由用户手动开启，按系统提示重启，解锁并确认开启。
5. 若安装失败或开关仍缺失，记录全能签提示和证书/描述文件类型，停止以相同条件反复安装。此包未实机验证，不保证通过全能签的具体安装流程能够触发入口。

GitHub 构建只使用临时签名，不含个人证书、私钥或 embedded.mobileprovision。需要全能签重新签名后才可按所用证书方式安装。包不包含游戏或游戏插件，不需要导入账号，无网络访问代码。
